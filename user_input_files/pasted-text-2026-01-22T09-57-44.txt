INR99 WordPress Plugin Suite

A comprehensive collection of WordPress plugins designed to integrate, extend, and white-label the INR99 learning management platform. This workspace contains all plugin repositories developed for the INR99 ecosystem.

Suite Overview

The INR99 WordPress Plugin Suite provides a modular approach to extending WordPress with powerful learning management capabilities. Each plugin serves a specific function within the ecosystem, from core LMS integration to media processing, live class connectivity, and license management. Together, these plugins transform a standard WordPress installation into a fully-featured learning management frontend capable of delivering courses, tracking progress, managing live sessions, and processing multimedia content.

The architecture follows WordPress best practices with object-oriented PHP, proper hook integration, and standards-compliant code structure. Each plugin operates independently but can be combined to create a comprehensive learning platform. The licensing manager ensures that all plugins can enforce proper license validation and automatic updates across the entire suite.

Prerequisites

Before installing any plugin from this suite, ensure your WordPress environment meets the following requirements. These requirements apply across all plugins and represent the minimum supported configuration.

WordPress version 5.0 or higher is required for all plugins, though version 6.0 or later is recommended for optimal compatibility with the block editor and modern WordPress features. PHP version 7.4 or higher is required, with PHP 8.0 or later recommended for improved performance and type safety. Each plugin follows WordPress coding standards and has been tested for compatibility with common security plugins, caching solutions, and hosting environments.

For server requirements beyond the WordPress minimums, consider that the PPTX Video Connector may require additional resources for media conversion tasks. The Live Class Connector requires outbound HTTPS access to video conferencing APIs. All plugins store settings in the WordPress options table, eliminating the need for custom database tables.

Quick Start for Development

To set up this workspace for development, begin by cloning the repository or downloading the plugin directories to your local development environment. Each plugin directory is self-contained and can be installed independently by copying the entire directory to your WordPress installation's wp-content/plugins/ folder.

For active development, create a symbolic link from your WordPress plugins directory to the plugin folder in this workspace. This allows you to edit files in the workspace while seeing changes immediately in your WordPress installation. For example, if your WordPress installation is at /var/www/html/wp-content/plugins/ and your workspace is at /workspace/, you would create a link using ln -s /workspace/inr99-cloud-lms-connector /var/www/html/wp-content/plugins/inr99-cloud-lms-connector.

After linking the plugins, activate them through the WordPress admin plugins page. Each plugin will add its own menu items and settings pages. The recommended activation order places the Licensing Manager first, followed by the Cloud LMS Connector, then the remaining plugins in any order that suits your workflow.

Integration Architecture

Understanding how these plugins work together helps in planning your WordPress configuration and troubleshooting potential issues. The architecture follows a hub-and-spoke model with the Licensing Manager serving as a central enforcement point.

The Cloud LMS Connector functions as the primary integration point, synchronizing course data, user accounts, and progress information between the INR99 cloud platform and your WordPress site. This plugin registers the most shortcodes and provides the deepest integration with WordPress content types through its Gutenberg blocks. All frontend course display, user dashboards, and progress tracking flows through this plugin.

The Live Class Connector extends the LMS experience by adding real-time session capabilities. It integrates with video conferencing platforms and displays upcoming sessions alongside regular course content. The connector retrieves session information through the central API client shared with other plugins in the suite.

The White-Label Launcher provides the branding infrastructure that makes the LMS feel like a native part of your WordPress site. This plugin handles the initial site provisioning and ongoing asset management for custom branding elements. When activated, it presents a setup wizard that connects your WordPress site to the INR99 provisioning API.

The PPTX Video Connector adds media processing capabilities for converting presentation files into video content. This plugin integrates with the broader LMS by making converted videos available as course resources. It maintains its own job queue for tracking conversion progress.

The Licensing Manager sits at the foundation of all other plugins, providing license validation, tier enforcement, and automatic update functionality. Other plugins use the public INR99_Gatekeeper class to check license status and restrict features based on the user's license tier. This centralized approach eliminates duplicate license checking code and ensures consistent enforcement across the entire suite.

Common Configuration Tasks

Several configuration tasks recur across multiple plugins and understanding them in context helps streamline the setup process. API credentials represent the most common configuration element, as each plugin communicates with the INR99 cloud platform through authenticated API calls.

API credentials are typically entered in the plugin's settings page, accessible through the WordPress admin menu under the plugin's designated menu item. The credentials consist of an API key and secret pair obtained from your INR99 account dashboard. These credentials authorize your WordPress site to communicate with the INR99 platform and should be treated as sensitive information protected from unauthorized access.

Shortcode placement represents another common task, as most plugins provide shortcodes for displaying content on WordPress pages and posts. The individual plugin README files document each available shortcode with its parameters and usage examples. Shortcodes can be added through the WordPress block editor, classic editor, or widget areas depending on your site's configuration.

User role management affects how different user types interact with the plugins. The LMS Connector creates custom user roles for instructors and students, while the other plugins respect WordPress's built-in role hierarchy. Review the role capabilities in each plugin's settings to ensure users have appropriate access levels.

Support and Resources

For additional documentation, API references, and troubleshooting guides, consult the individual README files in each plugin directory. These files contain detailed information specific to each plugin's features, configuration options, and usage patterns.

For issues specific to a particular plugin, check the plugin's settings page for diagnostic information and error logs. The plugins capture detailed error information that helps identify configuration problems, API authentication issues, and compatibility conflicts.

For questions about the INR99 platform itself, including account management, billing, and content creation tools, contact INR99 support through your account dashboard. The WordPress plugins in this suite focus on the technical integration and do not control account-level settings or subscription management.

License

Each plugin in this suite requires a valid INR99 license for full functionality. The Licensing Manager handles license validation and enforces tier restrictions. See the individual plugin README files for license requirements and the licensing manager documentation for activation instructions.
